# Rekindle & Rise UX Flows

## 1. Onboarding Flow

### Goal
Help a new user understand the product, create an account, and reach a meaningful first experience quickly.

### Flow
1. Landing page introduces the mission and values.
2. User chooses to create an account.
3. User selects role: survivor, supporter, organization, or other.
4. User enters basic account details and age/consent information.
5. User configures privacy preferences and account visibility.
6. User completes optional profile setup.
7. User lands on a personalized home experience with community and journal entry options.

### Key UX considerations
- Make the experience calm, reassuring, and non-clinical.
- Clearly explain privacy choices and consent.
- Reduce friction for first-time users.

## 2. Community Participation Flow

### Goal
Help users discover and engage with supportive community spaces.

### Flow
1. User lands on home feed.
2. User browses recommended groups and events.
3. User joins one or more relevant groups.
4. User views posts, comments, and announcements.
5. User creates or replies to a discussion post.
6. User can report, mute, or block content if needed.

### Key UX considerations
- Make groups feel welcoming and moderated.
- Provide easy ways to find relevant communities.
- Keep safety tools visible and understandable.

## 3. Journal Experience Flow

### Goal
Help users engage in private reflection without feeling overwhelmed.

### Flow
1. User opens the journal from the main navigation.
2. User selects a prompt, mood check-in, or blank entry.
3. User writes an entry.
4. User saves the entry and optionally attaches media.
5. User can export, delete, or view past entries.

### Key UX considerations
- Use gentle language and supportive prompts.
- Make privacy and deletion controls obvious.
- Support short, low-friction entry creation.

## 4. Event Discovery Flow

### Goal
Help users discover local and virtual events that match their interests.

### Flow
1. User browses events from home or community pages.
2. User filters by location, topic, or format.
3. User reviews event details and host information.
4. User RSVPs or saves the event.
5. User receives reminders and can provide feedback later.

### Key UX considerations
- Keep event details readable and accessible.
- Support trust through verified organization presentation.
- Make RSVP actions simple and clear.
