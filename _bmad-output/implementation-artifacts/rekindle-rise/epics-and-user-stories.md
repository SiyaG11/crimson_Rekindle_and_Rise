# Rekindle & Rise Epics and User Stories

## Epic 1: Foundation and Account Experience

### Goal
Provide a secure, welcoming entry point for users and establish the core identity model for the platform.

### Stories
- EP1-S1: As a new user, I want to create an account and select my role, so that I can join the platform in a way that fits my needs.
- EP1-S2: As a new user, I want to complete onboarding and set privacy preferences, so that I understand the product and control my personal information.
- EP1-S3: As a parent or guardian, I want to create a linked account for a child under 13, so that a minor can participate under approved supervision.

## Epic 2: Privacy, Safety, and Consent Controls

### Goal
Protect user trust by making sensitive data handling, consent, and privacy controls clear and reliable.

### Stories
- EP2-S1: As a user, I want my sensitive profile and journal data to default to private, so that I can share at my own pace.
- EP2-S2: As a user, I want to update my privacy settings and delete my data, so that I retain control over my information.
- EP2-S3: As a moderator, I want to review and act on reports, so that the community remains safe and respectful.

## Epic 3: Community and Social Connection Experience

### Goal
Create a supportive community space where users can discover groups, participate in discussion, chat in real time, and build meaningful connections.

### Stories
- EP3-S1: As a user, I want to browse and join community groups, so that I can connect with people who share my interests or location.
- EP3-S2: As a user, I want to create and reply to posts, so that I can participate in community conversations.
- EP3-S3: As a user, I want to send and receive real-time messages within community spaces, so that I can connect more directly with others.
- EP3-S4: As a user, I want to follow others and share inspirational stories or recovery updates, so that I can build a supportive network around my journey.
- EP3-S5: As a user, I want to report or mute harmful content, so that I can interact safely.

## Epic 4: Private Journal and Reflection Experience

### Goal
Provide a private, gentle journaling experience that supports reflection, growth, and emotional well-being.

### Stories
- EP4-S1: As a user, I want to create journal entries with prompts, missions, and free text, so that I can reflect on my recovery journey in a guided way.
- EP4-S2: As a user, I want to save, edit, and delete journal entries, so that I can manage my private content.
- EP4-S3: As a user, I want to export my journal entries, so that I can preserve my reflections outside the platform.

## Epic 5: Events and Organization Discovery

### Goal
Help users discover events, initiatives, and organizations that are relevant, location-based, and trustworthy.

### Stories
- EP5-S1: As a user, I want to browse upcoming events on a location-based calendar, so that I can find local or virtual opportunities to engage.
- EP5-S2: As a user, I want to view event details and RSVP, so that I can participate with confidence.
- EP5-S3: As an organization representative, I want to publish event or initiative updates, so that I can share opportunities with the community.

## Epic 6: Moderation, Governance, and Administration

### Goal
Support trust, compliance, and safe operations for the platform as the community grows.

### Stories
- EP6-S1: As a moderator, I want to review pending content and approve or remove posts, so that the community standards are upheld.
- EP6-S2: As an administrator, I want to verify organization accounts, so that trusted organizations can participate.
- EP6-S3: As an administrator, I want to audit moderation decisions and account actions, so that operations remain accountable and transparent.

## Implementation Order
1. Foundation and account experience
2. Privacy, safety, and consent controls
3. Community and discussion experience
4. Private journal experience
5. Events and organization discovery
6. Moderation, governance, and administration
